# CreaDock MVP Scope

CreaDock is implemented as an interactive creator-commerce MVP. The creator workspace supports storefront configuration, digital-product upload and publishing, course and lesson authoring, bookable services and availability, membership plans, audience records, broadcasts, welcome sequences, analytics, and platform administration.

The public storefront supports email signup, in-app product checkout, digital-delivery entitlements, membership joining, booking confirmation, and course lesson-progress recording. MVP checkout creates a paid CreaDock order without charging a card; membership joining creates an active in-app subscription; broadcast sending updates campaign state without delivering external email.

Live payment processing, external email delivery, calendar-provider events, custom-domain DNS, advanced cart persistence, and post-purchase gated-content authorization are intentionally deferred from this MVP. The existing domain model and integration documentation preserve a path to add these capabilities when the product moves beyond prototype validation.
